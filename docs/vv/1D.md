# 1D Euler Problems

One-dimensional inviscid flow problems solved with the compressible
Euler equations.  Each test is run on four successively refined
meshes (×1, ×2, ×4, ×8) and verified against an exact analytical
solution.  The acceptance criterion is a maximum pointwise relative
error below 1–1.5 % on the finest mesh, evaluated at selected probe
locations away from discontinuities.

!!! info "Regression status (2026-05-15)"

    All four 1D cases (Sod79, Ein91, Tor99, Noh87) are wired into CTest
    (`ctest -R 'Sod79|Ein91|Tor99|Noh87' --preset release`) with
    `check.py` scripts mirroring MOSE `verify.py` (1 % threshold on
    rho/u/p/sie, 1.5 % on p for Noh87 near-vacuum).  The four tests pass
    on the default ×4 mesh.

    Developer-side cross-check vs MOSE (`field.tec`, K=0 layer of the
    3-D wedge), with identical compiler (`ifx 2024.1`) and identical
    flags (`-xHost -O3 -funroll-loops -inline -ffast-math`):

    - **Iteration 1 cell-by-cell** (Q2D-O3 vs MOSE-O3 after one
      time step): **bit-exact** for rho/u/p/T/g/R (max\|abs\| = 0
      exactly).  → no kernel/wiring divergence.
    - **Final time t=1.0 (821 iterations) drift permutation matrix**:

        | Comparison | rho max\|abs\| | p max\|abs\| |
        |---|---|---|
        | Q2D-O3 vs MOSE-O3 | 3.3e-7 | 7.2e-8 |
        | Q2D-O3 vs Q2D-strict (same source) | 1.6e-7 | 3.6e-8 |
        | MOSE-O3 vs MOSE-strict (same source) | 4.9e-7 | 1.1e-7 |
        | **Q2D-strict vs MOSE-strict** | **1.05e-9** | 2.3e-10 |

      Where "strict" means rebuilt with `cmake/SetFortranFlags.cmake`
      lines 218–223 commented out (no `-ffast-math`/`-fp-model fast=2`).

    The matrix shows that toggling `-ffast-math` on the **same source
    code** produces O(1e-7) drift for both Q2D and MOSE individually
    (the flag enables non-deterministic FP reordering that, combined
    with stiff near-vacuum p~1e-15 sound-speed sensitivity, amplifies
    over 821 time steps).  With strict-FP build for both solvers, the
    residual Q2D-strict vs MOSE-strict drift is 1e-9 — the *true*
    structural-difference contribution from Q2D 2-D strip (4-face BC,
    K=1) vs MOSE 3-D wedge (6-face BC, K=2), 330× smaller than the
    `-ffast-math` noise.

    For Tor99 (MUSCL+vanleer+HLLE++ stable, p≥0.1) the same machine-eps
    seed stays bounded at 1–2 ULPs final drift; no stiff-amplification.

    Strict numerical equivalence between Q2D and MOSE on Noh87 would require
    dropping `-ffast-math` from the shared `open-hydra` CMake preset
    (perf cost ~10–30 %).  The residual 1e-9 Q2D-strict vs MOSE-strict
    drift is acceptable structural noise, well below check.py 1.5 %
    threshold and V&V tolerances.

    Mesh-refinement plots (×1/×2/×4/×8) and L1/Linf-probe convergence
    tables are available in [Mesh-refinement convergence
    summary](convergence-table-1D.md).

!!! note "Q2D 1D test layout (peculiarity #1)"

    Q2D runs 1D problems on a thin 2D Cartesian strip ($n_j = 1$ or
    $n_j = 2$ depending on ghost-cell convention).  Faces 3 and 4 of
    the single block are set to symmetry (`type = 300`), so the
    transverse direction degenerates and the residual reduces to the
    pure 1D Euler system.  The 4-face block layout follows
    [Boundary Conditions — Face Numbering](../user/boundary-conditions.md#face-numbering).

## Sod Shock Tube

The classical shock-tube problem of Sod (1979).  The initial
left–right discontinuity generates a right-travelling shock, a
contact discontinuity, and a left-travelling rarefaction fan.  This
is a standard benchmark for first- and second-order shock-capturing
schemes.

**Reference:** G. A. Sod, _J. Comput. Phys._ **27** (1978) 1–31.

### Initial conditions

| Region | $\rho$ | $u$ | $p$ | $\gamma$ |
|---|---|---|---|---|
| Left ($x < 0.5$) | 1.0 | 0 | 1.0 | 1.4 |
| Right ($x \geq 0.5$) | 0.125 | 0 | 0.1 | 1.4 |

### Numerical setup

| Parameter | Value |
|---|---|
| Domain | $[0, 1]$ |
| Final time | $t = 0.2$ |
| Time scheme | RK3 |
| CFL | 0.9 |
| Space reconstruction | MUSCL |
| Flux limiter | MC |
| Riemann solver | SLAU |

## Einfeldt Double Rarefaction

The "123 problem" of Einfeldt et al. (1991): two streams moving apart
generate two expanding rarefaction fans separated by a nearly vacuum
region.  The near-vacuum state stresses the positivity of density and
pressure, making it a challenging test for numerical Riemann solvers.

**Reference:** B. Einfeldt et al., _J. Comput. Phys._ **92** (1991)
273–295.

### Initial conditions

| Region | $\rho$ | $u$ | $p$ | $\gamma$ |
|---|---|---|---|---|
| Left ($x < 0.5$) | 1.0 | -2.0 | 0.4 | 1.4 |
| Right ($x \geq 0.5$) | 1.0 | +2.0 | 0.4 | 1.4 |

### Numerical setup

| Parameter | Value |
|---|---|
| Domain | $[0, 1]$ |
| Final time | $t = 0.15$ |
| Time scheme | RK3 |
| CFL | 0.9 |
| Space reconstruction | MUSCL |
| Flux limiter | Van Leer |
| Riemann solver | HLLE |

## Noh Implosion Problem

The Noh (1987) infinite-strength implosion: a gas moving inward at
unit velocity is brought to rest by an outward-propagating shock.
The problem has an exact solution with a very strong density jump.
An equivalent configuration, adopted in this case, presents an
initial configuration with two regions at opposite velocity and same
thermodynamic state.

**Reference:** W. F. Noh, _J. Comput. Phys._ **72** (1987) 78–120.

### Initial conditions

| Region | $\rho$ | $u$ | $p$ | $\gamma$ |
|---|---|---|---|---|
| Left ($x < 0.5$) | 1.0 | +1.0 | 1e-15 | 1.4 |
| Right ($x \geq 0.5$) | 1.0 | -1.0 | 1e-15 | 1.4 |

### Numerical setup

| Parameter | Value |
|---|---|
| Domain | $[0, 1]$ |
| Final time | $t = 1.0$ |
| Time scheme | RK3 |
| CFL | 0.5 |
| Space reconstruction | first-order |
| Riemann solver | HLLE |

## Toro Test Case 3

Modified Sod problem from Toro's 1999 test collection: non-zero left
velocity ($u_L = 0.75$) added to the standard Sod left state.  The
resulting wave pattern is a left-going **transonic rarefaction** (with
a sonic point inside the fan, where $u - a$ changes sign across the
expansion), a right-going contact discontinuity, and a right-going
shock — exercising the solver's entropy fix on the transonic rarefaction
and the standard shock-capturing branch on the right-moving compression.

**Reference:** E. F. Toro, _Riemann Solvers and Numerical Methods for
Fluid Dynamics_, 2nd ed., Springer, 1999.

### Initial conditions

| Region | $\rho$ | $u$ | $p$ | $\gamma$ |
|---|---|---|---|---|
| Left ($x < 0.3$) | 1.0 | 0.75 | 1.0 | 1.4 |
| Right ($x \geq 0.3$) | 0.125 | 0 | 0.1 | 1.4 |

### Numerical setup

| Parameter | Value |
|---|---|

| Final time | $t = 0.2$ |
| Time scheme | RK3 |
| CFL | 0.9 |
| Space reconstruction | MUSCL |
| Flux limiter | Van Leer |
